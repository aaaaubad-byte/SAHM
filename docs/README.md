# فهرس وثائق SAHM | سهم

هذا الفهرس يميز الوثائق النشطة عن سجلات المراحل التاريخية حتى لا تختلط التعليمات القديمة بالحالة الحالية.

## المراجع النشطة

1. `../SAHM_Association_Creation_and_Installments_Reference_AR_v2.md` — المرجع الوظيفي العام وقواعد الجمعية والأقساط والقرعة.
2. `SAHM-UNIFIED-ASSOCIATION-FLOW-SPEC.md` — المرجع الموحد الحالي لإنشاء الجمعيات والدعوات وطلبات الانضمام.
3. `SAHM-IMPLEMENTATION-PLAN.md` — خطة التنفيذ الفنية المرتبطة بالمرجع الموحد.
4. `SAHM_ENGINE_DATA_CONTRACT_AR.md` — عقد الربط بين المحرك والبيانات وSupabase.
5. `SAHM_FULL_SYSTEM_AUDIT_INITIAL_BASELINE_AR.md` — سجل التدقيق الأساسي، ويُقرأ بوصفه خط أساس بتاريخ محدد لا تقرير حالة لحظي.
6. `internal/SUPABASE_IMPLEMENTATION_PROGRESS_AR.md` — الحالة التشغيلية الأحدث؛ القسم الأول هو الحالي، والأقسام اللاحقة سجلات تاريخية.
7. `internal/SUPABASE_DATABASE_DESIGN_AR.md` — التصميم العلائقي مع ملاحق التنفيذ؛ الأعداد التاريخية داخله لا تتقدم على الفحص الحي.
8. `internal/SUPABASE_SETUP_AR.md` — إعدادات البيئة ومتطلبات ما قبل الإطلاق.

## وثائق تاريخية أو مساندة

- `SAHM_ASSOCIATION_JOIN_WORKFLOW_REFERENCE_AR.md` — نسخة سابقة استبدلها المرجع الموحد الحالي.
- ملفات `internal/BATCH*_*.md` و`internal/BATCH_A_BASELINE_AR.md` — سجلات تقدم وقرارات مرحلية بتاريخها؛ لا تُستخدم كتعليمات تنفيذ حالية.
- `internal/UI_RESTRUCTURE_PLAN_AR.md` — خطة قديمة أُعلن داخلها صراحةً إلغاء خطوات تقسيم الواجهة؛ لا تُنفذ مقترحات النقل الواردة فيها.
- `internal/SUPABASE_INITIAL_AUDIT_AR.md` — تدقيق تأسيسي سابق يصف حالة قاعدة البيانات قبل إنشاء مخطط التطبيق.

## قاعدة التعامل مع الوثائق

عند التعارض، الأولوية للمرجع الوظيفي V2 ثم المرجع الموحد الحالي ثم خطة التنفيذ وعقد البيانات، مع إعادة التحقق من GitHub وSupabase قبل أي تغيير. لا تُحذف السجلات التاريخية لمجرد قدمها؛ تُوسم أو تُنقل إلى الأرشيف بعد التحقق من عدم وجود روابط تعتمد مساراتها.
