## نتائج الجرد وما لم يُحذف

- انخفض عدد قواعد CSS وفق ماسح الجرد نفسه من **755 إلى 622 قاعدة** بعد إزالة الأصناف الميتة.
- وُجدت **161 مجموعة محددات** يظهر المحدد الواحد منها في أكثر من قاعدة. لم تُحذف هذه القواعد آلياً؛ لأن اختلافها في الخصائص أو موضعها داخل `@media` أو ترتيبها قد يكون جزءاً من الـ cascade والاستجابة للشاشات.
- لم يظهر تكرار حرفي كامل لقاعدة CSS بنفس المحدد والسياق ومجموعة التصريحات، ولم يظهر تكرار خاصية داخل قاعدة واحدة في الفحص النصي.
- ظهرت ثلاثة معرفات HTML مكررة مرتين: `loginForm`, `loginEmail`, `loginPassword`. موضعاها نموذج الدخول الأولي في HTML ونموذج `welcome()` الديناميكي. تُركت دون تعديل إلى حين فحص DOM الفعلي أثناء الانتقال بين حالتي التهيئة والدخول.
- تشابه أسماء الدوال بين `sahm-data.js` و`sahm-supabase-data.js` لم يُعامل كحذف؛ فهما طبقتا بيانات منفصلتان (محلية وبعيدة) تشتركان في عقد عمليات واحد.
- لم يُحذف أي منطق للقرعة أو الجمعيات أو العضويات أو الأقساط أو الإشعارات أو المصادقة.

### 5. إصلاح أداة اختبار موجودة
كان اختبار الإشعارات لا يتوافق مع تطور الواجهة: كان يفترض أن `audit` تأتي مباشرة بعد `notifications`، ثم ينتظر روابط `data-go` قد استبدلها التطبيق بزر `data-action=notification-open` وبيانات `data-related-id`. عُدّل حدّ الاستخراج إلى الدالة التالية الفعلية (`news`)، وتم تحديث الاختبار ليتحقق من بيانات الإشعار ومن توجيه المعالج إلى `join-request-status`. لم يتغير كود الإشعارات الإنتاجي.
