## ما نُفذ

- أذرع المحددات المحذوفة: 136.
- قواعد CSS الكاملة التي لم يبق لها أي محدد صالح: 133.

### 2. إزالة متغيرات تصميم ميتة
أزيلت تعريفات المتغيرات الخمسة غير المشار إليها في أي موضع تشغيلي: `--gold`, `--card`, `--red`, `--blue`, `--radius`. بقيت بقية متغيرات التصميم كما هي.

### 3. إزالة دوال مساعدة غير مستخدمة
أزيلت من `sahm-supabase-data.js` الدالتان الخاصتان غير المستدعاتين:

لم تكن أي منهما جزءاً من واجهة التصدير العامة، ولم يوجد لها استدعاء في ملفات التطبيق.

### 4. اختبار منع رجوع التكرار الميت
أضيف اختبار عقدي يتحقق من عدم عودة أصناف CSS المحذوفة أو متغيراتها، ومن عدم عودة الدالتين غير المستخدمتين.

## نتائج الجرد وما لم يُحذف

- انخفض عدد قواعد CSS وفق ماسح الجرد نفسه من **755 إلى 622 قاعدة** بعد إزالة الأصناف الميتة.
- وُجدت **161 مجموعة محددات** يظهر المحدد الواحد منها في أكثر من قاعدة. لم تُحذف هذه القواعد آلياً؛ لأن اختلافها في الخصائص أو موضعها داخل `@media` أو ترتيبها قد يكون جزءاً من الـ cascade والاستجابة للشاشات.
- لم يظهر تكرار حرفي كامل لقاعدة CSS بنفس المحدد والسياق ومجموعة التصريحات، ولم يظهر تكرار خاصية داخل قاعدة واحدة في الفحص النصي.
- ظهرت ثلاثة معرفات HTML مكررة مرتين: `loginForm`, `loginEmail`, `loginPassword`. موضعاها نموذج الدخول الأولي في HTML ونموذج `welcome()` الديناميكي. تُركت دون تعديل إلى حين فحص DOM الفعلي أثناء الانتقال بين حالتي التهيئة والدخول.
- تشابه أسماء الدوال بين `sahm-data.js` و`sahm-supabase-data.js` لم يُعامل كحذف؛ فهما طبقتا بيانات منفصلتان (محلية وبعيدة) تشتركان في عقد عمليات واحد.
- لم يُحذف أي منطق للقرعة أو الجمعيات أو العضويات أو الأقساط أو الإشعارات أو المصادقة.

### 5. إصلاح أداة اختبار موجودة
كان اختبار الإشعارات لا يتوافق مع تطور الواجهة: كان يفترض أن `audit` تأتي مباشرة بعد `notifications`، ثم ينتظر روابط `data-go` قد استبدلها التطبيق بزر `data-action=notification-open` وبيانات `data-related-id`. عُدّل حدّ الاستخراج إلى الدالة التالية الفعلية (`news`)، وتم تحديث الاختبار ليتحقق من بيانات الإشعار ومن توجيه المعالج إلى `join-request-status`. لم يتغير كود الإشعارات الإنتاجي.

### 6. تنظيف تصريحات CSS المتطابقة
أزيلت **133** تصريحات CSS متطابقة بالقيمة والأهمية من مجموعات لها المحدد نفسه ونطاق `@media` نفسه، مع الإبقاء على آخر نسخة فعالة. شمل ذلك 29 مجموعة محددات. انخفض حجم CSS من 77,868 إلى 74,184 حرفاً، بتوفير 3,684 حرفاً إضافياً. بقيت جميع القيم المختلفة والاختلافات المتجاوبة كما هي.

### 7. إزالة التعارضات المتجاوزة داخل المحدد نفسه
بعد تثبيت التصريحات المتطابقة، أزيلت **208** تصريحات أقدم أصبحت مستبدلة بتصريح لاحق للمحدد نفسه وفي نطاق الاستجابة نفسه، مع أولوية مساوية أو أعلى. شملت المعالجة التعديلات التاريخية على الترويسة، شريط التنقل، بطاقات الرئيسية، ونموذج إنشاء الجمعية. أبقينا 28 حالة قد تكون صيغ توافق/احتياط (مثل `env()` و`var()` و`calc()` ووحدات viewport الحديثة) للمراجعة ولم نحذفها. أضيف اختبار مستقل لمنع عودة التصريحات المتجاوزة غير الاحتياطية.

### 8. إزالة القواعد الفارغة
أزلت 27 قاعدة CSS فارغة و5 كتلة شرطية فارغة، وأضيف اختبار يمنع رجوعها. انخفض حجم CSS من 69,627 إلى 68,206 حرفاً.
