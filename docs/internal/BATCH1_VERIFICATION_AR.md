## 3. تحقق تكاملي ساكن للمعاينة

- جرى جلب `Sahm_Preview_ROLE_SEPARATION.html` من الفرع.
- نجح تحليل بناء JavaScript للنصين البرمجيين غير الفارغين في الملف.
- جرى فحص أسماء الواجهات البرمجية التي تشير إليها المعاينة؛ لم تظهر إحالات إلى دوال غير موجودة في `SahmCore` أو `SahmData`.
- تأكد اختبار منفصل من ترحيل بيانات v3 إلى v4 وأرشفة النسخة القديمة.

**هذا فحص ساكن واختبار وظائف، وليس تشغيلًا فعليًا للصفحة في Chrome.** لا يثبت سلامة DOM أو التنقل أو جميع تفاعلات الواجهة في المتصفح.

## 4. تشغيل Node الأصلي ونتيجة CI

أضيف سير عمل GitHub Actions لتشغيل:

```bash
node --test tests/
```

عند آخر تحقق من خلال واجهة المستودع لم تظهر حالة CI أو نتيجة تشغيل مرتبطة بالالتزام الذي أضاف سير العمل. لذلك لا أسجل أن أمر Node الأصلي قد اجتاز؛ نتيجة 36/36 أعلاه تخص تشغيل ملفات الاختبار في بيئة JavaScript المعزولة.

## 5. مسائل وظيفية لا يجوز اعتبارها محسومة

1. **تجاوز النصاب:** المرجع يحدد احتساب النصاب بالأشخاص، لكنه لا ينص على تجاوز إداري. `performDraw` يقبل حاليًا `overrideQuorum`. لا تعرض الواجهة هذا الخيار قبل اعتماد قاعدة صريحة.
2. **السداد المسبق:** `recordPaid` يقبل تسجيل قسط مستقبلي ويحفظ `statusAtRecord`. المرجع لا يحسم صراحةً سياسة الدفع المسبق.
3. **تعديل إعدادات الدورات:** يجب الحفاظ على إعدادات وسجلات الدورات السابقة؛ وأي تغيير مستقبلي يجب ألا يعيد كتابة تاريخ دورة بدأت.

هذه نقاط قرار، وليست أخطاء اختبارات يجوز حسمها بافتراض غير موثق.

## 6. حدود الدفعة الأولى وما بقي

- يلزم تشغيل سير CI فعليًا والتحقق من نتيجة `node --test tests/`.
- يلزم فتح المعاينة في Chrome والتحقق من مسارات المدير والمشارك الأساسية مع v4 دون إعادة تصميمها.
