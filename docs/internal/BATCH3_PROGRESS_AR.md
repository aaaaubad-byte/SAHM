# حالة إعادة ربط واجهة سهم بمرجع V2

**آخر تحديث:** 2026-11-13  
**المستودع:** `aaaaubad-byte/SAHM`  
**فرع التنفيذ الحالي:** `main`  
**فرع الدمج السابق:** `feature/sahm-final-preview-product`  
**الواجهة المستهدفة:** `Sahm_Preview_ROLE_SEPARATION.html`

## القيود الهندسية المستمرة
- تبقى الواجهة داخل ملف HTML الحالي؛ لا تقسيم إلى ملفات واجهة جديدة لمجرد إعادة التنظيم.
- المحافظة على شاشة `home()` والشريط العلوي `renderTopbar()` والتنقل العلوي `nav()` كما هي بصريًا وسلوكيًا.
- مرجع السلوك هو مواصفات سهم V2، لا المسارات القديمة أو حالات الدفع المتعارضة.
- لا دمج إضافي إلى `main` إلا بتوجيه المستخدم.

## الإنجاز المدمج (PR #34)
- توصيل الواجهة بمحرك `SahmApp` وإزالة مخزن الواجهة الموازي والإسقاطات الوهمية `localGroups` و`payments`.
- ربط إنشاء الجمعية، الدورات وحساب أول قرعة، الأعضاء والدعوات والانضمام، الأقساط وتسجيل الاستلام وتصحيحه، القرعة والأهلية، المحادثة والإشعارات وسجل الأحداث.
- حذف مسارات إثبات التحويل والمراجعة والتصويت والمحاكاة القديمة.
- ربط مرشحات الأقساط وتذكير المجموعة، واستعادة إجراءات دخول المعاينة المحلية.
- PR #34: https://github.com/aaaaubad-byte/SAHM/pull/34
- Merge commit: `e06726356d18c247dcace5390bab1f140e8f0771`.

## التحقق المنفذ
- اختبارات `tests/core.test.js` و`tests/data.test.js`: **36/36 ناجحة** ضمن بيئة JavaScript متوافقة مع الاختبارات.
- تحليل JavaScript المضمن وفحص توصيل الإجراءات نجحا.
- مقارنة `home()` و`renderTopbar()` و`nav()` مع المصدر السابق أشارت إلى التطابق الحرفي.
- تشغيل GitHub Actions الأصلي في Node 22 كشف خللًا في أمر سير CI، وليس في الاختبارات نفسها: `node --test tests/` لا يفتح مجلد الاختبارات على هذا الإصدار، وانتهى إلى `MODULE_NOT_FOUND`.
- أُصلح أمر سير CI ليستخدم `node --test tests/*.test.js`، وأضيف فرع إصلاح مستقل لتشغيله والتحقق من النتيجة.
- لم يُسجل بعد نجاح CI الرسمي بعد هذا الإصلاح؛ يجب انتظار تشغيله.

## حدود المعاينة
- التطبيق الحالي معاينة محلية تعتمد على التخزين المحلي؛ لا توجد مزامنة خادمية أو قاعدة مشتركة أو Push ضمن هذه الدفعة.
- رمز الدخول `246810` ثابت ومحاكاة محلية فقط؛ لا يرسل SMS ولا يمثل تحققًا إنتاجيًا.
- لم يتم اختبار متصفح حي أو اختبار بصري على هاتف.
- مسائل السياسة التي تحتاج اعتمادًا من مرجع V2، ومنها تجاوز النصاب والسداد المسبق، لا تُحسم بافتراضات تنفيذية.
