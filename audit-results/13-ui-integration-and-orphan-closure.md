- الملفات المقروءة: Sahm_Preview_ROLE_SEPARATION.html، sahm-managed-group.js، sahm-managed-group.css
- نمط الفحص: قراءة ساكنة، دون تعديل أو تشغيل.

## 1. الأقسام النهائية

**CONFIRMED — المدير: عشرة أقسام**
1. التحصيل
2. القرعات
3. الأسهم
4. الأعضاء
5. الدعوات
6. الدردشة

**CONFIRMED — العضو**

## 2. نتائج الربط والفجوات

### F-13-01 — إدارة الرابط العام بلا مسار دخول ظاهر

**CONFIRMED**
- شاشة member-reception مسجلة في ALL_SCREEN_REGISTRY، ودالة memberReception موجودة.
- أزرار create/pause/resume/rotate/revoke-group-link وطلب getPublicLinkStatus موجودة في HTML.
- لكن لم يظهر في HTML أو sahm-managed-group.js أي استدعاء go('member-reception') أو data-go='member-reception' أو منتج route آخر واضح ينقل المدير إلى هذه الشاشة.
- شاشة manager workspace النهائية لا تحتوي قسم استقبال أعضاء أو تحكم الرابط؛ قسم الدعوات يدير الدعوات وطلبات الانضمام فقط.

**النتيجة:** إدارة دورة حياة الرابط العام موجودة ككود، لكن لا يظهر لها مسار وصول فعلي من تدفق المدير الحالي. تصنيف الوظيفة: DISCOVERED / DEPRECATED CANDIDATE على مستوى الشاشة غير الموصولة، لا حذف RPC أو الوظيفة. يجب تحديد مكان إدارة الرابط في التصميم الجديد قبل التنفيذ.

### F-13-02 — عمليات إدارة الأعضاء والأسهم غير متاحة في واجهة المدير

**CONFIRMED**
- قسم الأعضاء يعرض قائمة قراءة فقط، إحصاءات، بحثاً وفلترة حسب حالة الأسهم.
- لا توجد أزرار أو مصادر أحداث لعمليات addShares أو removeShares أو removeMember في HTML أو sahm-managed-group.js.
- RPC لهذه العمليات موجودة في طبقة البيانات/قاعدة البيانات بحسب جرد 07a/07b.

**النتيجة:** لا تخلط وجود RPC مع وجود قدرة مستخدم. واجهة المدير الحالية لا تعرض هذه العمليات. يلزم قرار منتج: هل هذه الوظائف متوقفة عمداً، أم يجب استعادتها في الواجهة الجديدة؟ لا تنفذها تلقائياً.

### F-13-03 — CSS يحتوي أصنافاً لا ينتجها HTML/JS الحالي

تم البحث الحرفي في HTML وsahm-managed-group.js ولم تظهر أي إحالات إلى هذه الأصناف، رغم وجود قواعد لها في CSS:
- mgd-new-member-actions
- mgd-member-tools
- mgd-filter-grid
- mgd-bulk-reminder
- mgd-member-shortcuts
- mgd-settings-heading
- mgd-group-facts
- mgd-facts
- mgd-reminder-icon
- mgd-member-summary

**التصنيف:** DEPRECATED CANDIDATE. لا تحذف الآن؛ تحقق من أن لا توجد ملفات أو قوالب خارج الملفات المقروءة تنتجها. لا يوجد ما يثبت أنها تؤثر في الشاشة الحالية.

### F-13-04 — قاعدة إخفاء إجراءات الأعضاء لا تخفي وظيفة مستخدمة حالياً

**CONFIRMED**
- CSS يحتوي قاعدة display:none!important على mgd-new-member-actions.
- لا ينتج HTML ولا JavaScript الحالي هذا الصنف.
- لذلك القاعدة بحد ذاتها موجودة، لكن لا يوجد دليل أن كتلة إجراءات ظاهرة حالياً أخفيت بها. هذا يصحح الأثر المحتمل في 05b: هي حالياً جزء من CSS المرشح للتقاعد، وليست دليلاً على زر مخفي في الشاشة الحالية.

### F-13-05 — مسارات التبويب القديمة ما زالت في بعض القوائم

- manager workspace الجديد يستخدم managedSection وعشرة أقسام ثابتة.
- بعض أسماء managed-tab وmanaged-back القديمة ما زالت مقبولة في handlers، بما فيها members/settings/news/chat/audit/overview.
- اختبارات ui-contract تتحقق من عدم ظهور مسارات مدير قديمة في واجهة المدير، لكن بقاء handler عام ليس دليلاً وحده على أنه مستخدم.
- التصنيف: DEPRECATED CANDIDATE؛ لا تحذف قبل تحديد جميع مصادر الأحداث.

### F-13-06 — pendingInvitees بلا تصريح محلي

- المتغير pendingInvitees يرد 19 مرة في HTML.
- تقرير المرحلة 01 وثّق الإسناد والقراءة دون let/var في مواضع محددة.
- لم يظهر تصريح في sahm-managed-group.js.
- هذا اعتماد على global ضمني في JavaScript غير الصارم، ويجب تحويله في المعمارية الجديدة إلى state صريح محدود النطاق.

## 3. خريطة عملية المدير والعضو

| القسم | عرض/إجراءات واجهة حالية | عقد البيانات الظاهر |
|---|---|---|
| التحصيل | ملخص التزامات، فلاتر، تحديد مطوّل، تسجيل مدفوع، تذكير | installmentRows / recordPaid / sendReminder |
| القرعات | بطاقات جولات وحالة التحصيل والجاهزية | getDrawHistory / getDrawReadiness |
| الأسهم | ملخص الأسهم وقائمة مع فلترة مؤهلة/فائزة/الكل | shareList |
| الأعضاء | إحصاءات وقائمة وبحث وفلترة | memberList |
| الدعوات | دعوات، طلبات انضمام، قبول/رفض/إلغاء، محرر دعوات | inviteList / approveJoinRequest / rejectJoinRequest / cancelInvite |
| الدردشة | قائمة رسائل ومحرر رسالة | sendMessage / chatPanel |
| الغرفة | غرفة القرعة، جدولة وعرض وتنفيذ | getDrawRoom / setDrawScheduledAt / performDraw / setDrawPresentationStatus |
| المعلومات | تاريخ الجمعية وأول قرعة وقيمة السهم وقواعدها | group detail snapshot |
| الإعدادات | حالة الاتفاق والاستقبال وإعدادات النشر | notification settings |
| السجل | أحداث الجمعية | getAuditLog |

**العضو:** overview + installments + shares + draws + communication، مع news/chat كمسارات فرعية داخل التواصل، وتفاصيل العضو/الدورة/القرعة حسب المسار.

## 4. ما لا يُحسم بهذا الفحص

- لا يثبت الفحص أن كل زر في كل شاشة يعمل runtime.
- لا يثبت صحة كل صلاحية؛ المرجع هو RLS وRPC.
- لا يحسم قرار استعادة add/remove shares أو remove member.
- لا يحسم مكان إدارة الرابط العام في التصميم الجديد.
- لا يبرر حذف الأصناف المرشحة دون فحص كامل لبقية القوالب والاختبارات.

## 5. التوصية

اجعل واجهة المدير الجديدة مطابقة للأقسام العشرة أعلاه، مع قرار منتج منفصل بشأن إدارة الرابط العام وإضافة/تقليل الأسهم وإزالة العضو. حافظ على بطاقات العضو الأربع الأساسية، واعتبر الأخبار والدردشة وتفاصيل العضو والدورة قدرات فرعية لا تضاعف عدد الأقسام الرئيسية.
