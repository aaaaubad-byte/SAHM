# سهم | SAHM — معاينة فرع Canva

هذه النسخة تنشر ملف المعاينة المرفق كما هو في `index.html`، مع إبقاء وثائق المواصفات الموجودة في الفرع دون تعديل.

## حالة النسخة
- الغرض: معاينة تفاعلية محلية لمراجعة الشاشات والتنقل والتصور البصري.
- ليست تطبيقاً إنتاجياً، ولا تتصل بقاعدة بيانات أو خادم.
- عمليات الدخول والاستعادة والإنشاء والانضمام والتحصيل والدعوات والرسائل وغيرها ليست عمليات حقيقية في هذه المعاينة.
- قد تحتوي المعاينة على بيانات ثابتة/تجريبية وسلوكيات توضيحية؛ لا تستخدم بياناتها لاتخاذ قرارات تشغيلية.
- لا تعتبر الشاشة مكتملة لمجرد ظهورها في المعاينة. حالة الاعتماد يحكمها سجل الشاشات والوثائق المرجعية.

## التشغيل والتثبيت
انشر جذر هذا الفرع كـ Static Site دون build command واجعل Publish Directory هو `.`. بعد فتح الرابط عبر HTTPS يمكن تثبيت التطبيق من قائمة المتصفح على الأجهزة المدعومة. يخزّن Service Worker هيكل التطبيق الأساسي لتوفير فتحه لاحقاً دون اتصال بعد أول زيارة ناجحة.

## حدود النسخة
قابلية التثبيت والعمل دون اتصال لا تعني وجود خادم أو قاعدة بيانات أو مصادقة أو تنفيذ فعلي للعمليات؛ تظل هذه النسخة مرحلة وسيطة للمراجعة وليست إصداراً نهائياً.

## مرجع التنفيذ
اقرأ `AGENTS.md` قبل أي تعديل. فرع العمل الحالي `sahm-canva` فقط. لا تنقل التغييرات إلى فروع التشغيل أو `main` قبل اكتمال المراجعة والاعتماد.
