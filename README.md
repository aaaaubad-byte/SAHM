# سهم | SAHM — فرع sahm-canva

## الغرض
هذا الفرع هو بيئة واجهات PWA تفاعلية لمراجعة شاشات سهم ومساراتها وقواعدها محلياً. الملف التنفيذي للواجهة هو `index.html`، وتبقى المواصفات المرجعية في الملفات المعتمدة دون استبدالها بهذا الملف.

## ما يعمل محلياً
- يبدأ التخزين الجديد دون حسابات أو جمعيات أو سجلات مستخدمين مزروعة مسبقاً.
- إنشاء الحساب وتسجيل الدخول واستعادة كلمة المرور وتعديل الملف الشخصي وتبديل الحسابات؛ تُحفظ هذه البيانات محلياً في المتصفح.
- إنشاء جمعية وحفظ إعداداتها وعضوية المنشئ.
- عند اختيار «مدير ومشارك»، يدخل المنشئ من المسار الإداري، وتُنشأ له الأسهم والأقساط والالتزامات وفق عدد أسهمه. أما «مدير فقط» فلا ينشأ له سجل عضوية أو التزامات.
- التحقق المحلي من رابط الجمعية وإرسال طلب انضمام وحفظ الطلب وإشعار مدير الجمعية محلياً.
- حفظ قائمة المدعوين والحضور لجلسة القرعة محلياً.
- حفظ تفضيل السمة، وتحديث مؤشر الاتصال عند انقطاع الشبكة أو عودتها.

## الحدود الحالية
- لا يتصل هذا الفرع بـ Supabase أو بأي خادم، ولا يحقق مصادقة إنتاجية أو مزامنة بين الأجهزة.
- الحسابات والبيانات المحلية متاحة فقط ضمن المتصفح ونطاق النشر نفسيهما؛ حذف بيانات الموقع أو تغيير المتصفح/الجهاز قد يفقدها.
- تأكيد التحصيل، إرسال التذكيرات والدعوات الشخصية، اعتماد طلبات العضوية، تنفيذ القرعة واعتماد نتائجها، والدردشة والأخبار المتصلة بالخادم ليست عمليات إنتاجية في هذا الفرع. لا تُعرض نتيجة نجاح لهذه العمليات ما لم تنفذ فعلياً عبر مصدر موثوق.
- كلمات المرور المحلية محمية بتجزئة مشتقة داخل المتصفح، لكن ذلك لا يجعل التخزين المحلي بديلاً عن مصادقة الخادم أو ضوابط الأمان الإنتاجية.
- حالة الاتصال وشريط التحديث يخصان تشغيل PWA وتحديث ملفات الواجهة، ولا يعنيان وجود اتصال بقاعدة بيانات.

## التشغيل والنشر
انشر جذر هذا الفرع كـ Static Site، دون أمر بناء، واجعل Publish Directory هو `.`. يتطلب التثبيت والعمل دون اتصال زيارة أولى ناجحة عبر HTTPS. يخزّن Service Worker هيكل التطبيق الأساسي، ويستخدم التصفح استراتيجية الشبكة أولاً للصفحة الرئيسية مع الرجوع إلى النسخة المخزنة عند تعذر الشبكة.

## التطوير
- اقرأ `AGENTS.md` والوثائق المرجعية قبل تعديل الشاشات أو قواعد المجال.
- ترتيب مصادر المتطلبات: `SAHM_NEW.md` ثم `SAHM_STRUCTURE_TREE.md` ثم `SAHM_SCREEN_REGISTER.md`. الملف الموحد مرجع تجميعي.
- لا تنقل التغييرات إلى `main` أو فروع التشغيل، ولا تعدّل قاعدة بيانات أو إعدادات نشر من هذا الفرع.
- حافظ على أحدث قرارات الواجهات المعتمدة، ولا تستكمل التفاصيل الموسومة بأنها غير محسومة بالتخمين.
