# سهم | SAHM — فرع الواجهات التفاعلية

هذا الفرع ينشر ملف `index.html` كما هو، مع الاحتفاظ بوثائق المواصفات وسجل الاعتماد. مرجع الشاشات وقواعدها هو `SAHM_NEW.md`، وفق ترتيب الأولوية الموضح في `AGENTS.md`.

## حالة البيانات والتشغيل

- يبدأ التطبيق بمساحة بيانات فارغة؛ لا تُنشأ حسابات أو جمعيات أو أعضاء أو إشعارات أو سجلات ثابتة مسبقاً.
- يدعم إنشاء عدة حسابات محلية والتبديل بينها على الجهاز والمتصفح نفسيهما لتجربة مسارات المستخدم والمدير والعضو.
- تُحفظ بيانات هذا الفرع محلياً في المتصفح. لا توجد مصادقة خادمية أو مزامنة بين الأجهزة أو اتصال بقاعدة Supabase في هذا الفرع.
- لا تمثل نجاحات إنشاء الحساب والجمعية وطلبات الانضمام سجلات إنتاجية على الخادم؛ إنها تغييرات محلية لهذا الفرع فقط.
- الإجراءات التي تتطلب مرجعاً خادمياً موثوقاً، مثل التحقق من الدعوات الشخصية واعتماد العضوية والتحصيل والتذكير وتنفيذ القرعة، تبقى غير متاحة ولا تعرض نجاحاً غير مؤكد.
- لا تستخدم بيانات هذا الفرع لاتخاذ قرارات تشغيلية، ولا تخزن فيه بيانات حساسة حقيقية.

## التشغيل والتثبيت

انشر جذر هذا الفرع كـ Static Site دون Build Command واجعل Publish Directory هو `.`. بعد فتح الرابط عبر HTTPS يمكن تثبيت التطبيق من قائمة المتصفح على الأجهزة المدعومة.

يخزن Service Worker ملفات غلاف التطبيق الأساسية لتسهيل فتحه دون اتصال بعد أول زيارة ناجحة. قابلية التثبيت والعمل دون اتصال لا تعني وجود خادم أو قاعدة بيانات أو مصادقة أو مزامنة.

## حدود التطوير

- لا تعدّل `main` أو فروع التشغيل من هذا الفرع.
- لا تنقل تغييرات الواجهات إلى التطبيق المرتبط بـ Supabase قبل اكتمال الجرد والمطابقة والموافقة.
- لا تفكك `index.html` أو تغيّر معمارية التطبيق قبل اكتمال مراجعة الشاشات والوظائف.
- لا تعتبر ظهور الشاشة أو نجاح تحليل JavaScript دليلاً على اختبارها وظيفياً على جهاز حقيقي.
